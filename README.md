**Circuit Arcade** is a high-performance, web-based gaming hub. Its flagship title, **Neon-Sink**, is a high-stakes digital heist platformer where you play as a Memory Scavenger infiltrating a corrupted data graveyard.

---

## 🎮 The Game: Neon-Sink

In **Neon-Sink**, you dive into the "Sinks"—deleted data fragments of a lost digital civilization. Your goal: steal Memory Cores and escape before your synchronization with the system fails.

### 🕹️ Gameplay Mechanics
- **Glitch Dash:** A high-velocity burst to clear gaps and dodge security.
- **Wall Jumping:** Scale vertical shafts by kicking off corrupted data walls.
- **Sync Rate:** A survival timer. Collect cores to stay synchronized; if you hit 0%, you de-rez.
- **Heist Objectives:** Collect the required amount of fragments to unlock the Exit Portal.

### 🛠️ Tech Stack
- **Frontend:** React 18 + Vite
- **Game Engine:** Phaser 3 (Arcade Physics)
- **Styling:** Neon-themed CSS with dynamic UI overlays
- **State Management:** Component-based state with an event-driven architecture
